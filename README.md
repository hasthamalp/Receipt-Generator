# District IT Cell Alappuzha – System Receipt Generator

This static web application is designed for a receipt/acknowledgement in the format requested.

## Fields
- Receipt / Token No.
- System / Item Received
- Serial Number
- Received From
- Date
- Time
- Remarks

## Print
Click **Print**. The print stylesheet hides the form and prints only the receipt. The browser print dialog can also be used to select **Save as PDF**.

## GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to a GitHub repository. Then:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
